# 一笔之间 · POCKET LINE

复古掌机风格的一笔画网页小游戏，使用原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。

[在线试玩](https://one-line-garden-x7p9.abloompony7.chatgpt.site)

## 玩法

- 按住任意圆点，沿已有线段移动；每条线只能经过一次，节点可以重复经过。
- 全程保持按住，中途松手会清空本次路线。
- 走错时，按住沿最后一条线回拖即可撤回，支持连续回退。
- 手机可用另一根手指按 B「撤回」键；电脑可按 Z 或 Backspace。
- 走完所有线段立即通关，随后松手不会重置结果。

## 功能

- 20 个固定关卡、关卡解锁与路线提示。
- 实时描线、节点吸附、触摸容错。
- 起笔、连接、撤回和通关的振动反馈（可关闭，需浏览器支持；iPhone Safari 不支持 Vibration API）。
- 可选音效，以及本地保存关卡进度与设置。
- 适配手机、平板与电脑。

## 本地运行

需要 Python 3。在仓库根目录运行：

```sh
python3 -m http.server 8080 --directory dist
```

在浏览器打开 http://localhost:8080 。

## 文件结构

```text
dist/
  index.html  # 页面结构
  style.css   # 复古掌机样式、响应式布局
  game.js     # 关卡、路线求解、交互、振动与存档
```

## 部署

将 `dist/` 作为静态站点目录部署即可，无构建步骤。振动 API 需要浏览器支持，建议使用 HTTPS。

## 验证

已校验 20 关均有合法解法，并在 Chromium 中验证逐关通关、松手重置、回拖撤回、死路回退、键盘撤回、双指撤回、提示与本地存档。手机振动触发已模拟验证，实际震感取决于设备和浏览器。
